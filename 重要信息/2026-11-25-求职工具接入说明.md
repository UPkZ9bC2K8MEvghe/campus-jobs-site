## 四、数据与通信约定

### localStorage 键
| 键 | 写入方 | 内容 |
|---|---|---|
| `campus-jobs-resume` | 工具页 | 用户简历纯文本（ATS / 简历体检输入时自动保存） |
| `campus-jobs-ats-prefill` | 主站 | `{tool, jd, company, role, id, ts}`，10 分钟有效，读取一次即删除 |
| `campus-jobs-apps` | 主站 | 投递记录；站外记录 id 以 `ext-` 开头，多出 `external/company/role/platform/salary` |
| `campus-jobs-tracker-migrated` | 主站 | 旧看板迁移完成标记（时间戳） |
| `campus-jobs-resume-threshold` | 主站 | 40 / 60 / 80 |
| `careerKit_tracker` | 旧工具页 | 旧看板数据，迁移后保留不删 |

### 预填数据 `tool` 字段
- 无 / 有 `jd`：打开 ATS 并填 JD，有简历则自动运行
- `iv`：打开面试题生成，填公司 + 岗位并生成
- `ats-open`：仅打开 ATS

### postMessage（同源）
- 主站 → 工具页：`{type: 'cj-ats-prefill'}`（iframe 已加载时触发读取预填）
- 工具页 → 主站：`{type: 'cj-open-apps'}`（点「求职追踪看板」时跳「我的投递」）

### URL 参数
| 参数 | 说明 |
|---|---|
| `view=tools` | 求职工具视图 |
| `tool=ai` | 切到效率小工具（默认 career，不写入 URL） |
| `ct=iv` / `ct=ats` | 深链直达面试题 / ATS |
| `company=` / `role=` | 配合 `ct=iv` 预填（各截断 80 字） |
| `rt=40` / `rt=80` | 简历匹配阈值（60 为默认，不写入 URL） |
| `st=resume` | 简历匹配快捷筛选（沿用原 `st` 机制） |
| `sort=resume` | 按简历匹配排序 |

## 五、算法说明

### 列表简历匹配分（轻量版）
- 内置约 150 个关键词（技术栈 / 专业方向 / 职能）。
- 分数 = 岗位文本中出现的关键词里，简历也命中的比例。
- 岗位侧可识别关键词 < 2 个时不打分（返回 null，不显示徽标，开启筛选时被隐藏）。
- 英文词按整词边界匹配。简历关键词只提取一次，每岗位分数缓存。
- 颜色：≥60 绿，30~59 黄，<30 红。
- 与原「我的专业 → 匹配 xx%」徽标相互独立。

### 完整 ATS（工具页原有六维算法）
关键词命中 45 + 频率 15 + 板块 15 + JD 词密度 10 + STAR 量化 10 + 内容丰富度 5 = 100。

### 面试题（工具页 `enhanceIV()`）
- 公司真题：`data/company-questions.json`，前缀匹配公司名（排除「京东方」→「京东」），按岗位关键词相关度取前 10 道，附原文链接。
- 通用题：`data/questions.json`，按岗位方向选 3 类各 2 道，可展开参考答案。
- 路径 `../../data/`，首次使用时加载（约 1.8MB）。
